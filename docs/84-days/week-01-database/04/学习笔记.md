### 修复的类型错误

`signToken(user)` 需要 `User` 类型（createdAt 是 number），但数据库返回的是 `SafeUser`（createdAt 是 Date）。在两个路由里加了 `.getTime()` 转换。

## 二、Resume 的数据流

```
前端选择 PDF 文件
    ↓ FormData
POST /api/interview/analyze-resume（Controller）
    ① 从 Token 拿 userId
    ② 接收文件 + 校验格式/大小
    ↓ 调 Service
resumeService.uploadAndAnalyze(userId, file)
    ① PDF 解析（parsePdf → rawText）
    ② AI 分析（analyzeResume → parsed + analysis）
    ↓ 调 Repository
resumeRepository.createResume({ userId, resumeName, size, rawText, resumeContext, analysis })
    ↓ Prisma
SQLite 数据库（Resume 表）
```

### 关键设计

**数据在第 3 步（AI 分析完成）后才一次存入数据库。** 不存在"半成品"数据。

## 三、现在改好的文件

### Schema（加了两字段）

```prisma
model Resume {
  ...
  rawText       String?   ← 新增：PDF 解析后的原始文本
  analysis      Json?     ← 新增：AI 分析结果
  ...
}
```

### Repository（只做创建）

```typescript
async createResume(data) {
  return prisma.resume.create({ data: { ... } });
}
```

### Service（处理全部逻辑）

```typescript
async uploadAndAnalyze(userId, file) {
  // ① PDF 解析
  const pdfResult = await parsePdf(buffer, file.name);
  // ② AI 分析
  const { parsed, analysis } = await analyzeResume(pdfResult.text);
  // ③ 全部存数据库
  return resumeRepository.createResume({ userId, resumeName, size, rawText, resumeContext: parsed, analysis });
}
```

### Controller（只做编排）

```typescript
// ① 拿 userId（从 Token）
// ② 拿文件 + 校验
// ③ 调 Service
const resume = await resumeService.uploadAndAnalyze(userId, file);
// ④ 返回
return NextResponse.json(resume);
```
