## 遇到的坑（踩过的雷）

1. **Prisma 类型首字母必须大写**：`string → String，int → Int，不管有没有 default。
2. **一对多关系两边都要声明**：InterviewSession 有 `user User`，User 必须有 `interviewSessions InterviewSession[]`，否则 db push 报错。
3. **SQLite 不支持 Prisma 级联删除**：删 Session 前必须手动 `prisma.message.deleteMany({ where: { sessionId } })`，否则会有外键约束错误。
4. **改完 schema 一定要跑 `prisma generate`，否则 Prisma Client 里没有新模型的 TS 类型，tsc 报错。
