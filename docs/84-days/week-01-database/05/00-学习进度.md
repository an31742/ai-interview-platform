## 遇到的坑（踩过的雷）

1. **Prisma 类型首字母必须大写**：`string → String，int → Int，不管有没有 default。
2. **一对多关系两边都要声明**：InterviewSession 有 `user User`，User 必须有 `interviewSessions InterviewSession[]`，否则 db push 报错。
3. **SQLite 不支持 Prisma 级联删除**：删 Session 前必须手动 `prisma.message.deleteMany({ where: { sessionId } })`，否则会有外键约束错误。
4. **改完 schema 一定要跑 `prisma generate`，否则 Prisma Client 里没有新模型的 TS 类型，tsc 报错。

## 额外收获：AI 省钱方案（2026-08-21 补充）

### 背景：DeepSeek 太贵，需要替换

当前项目里用的是 `OpenAI SDK 通用格式`（baseURL + apiKey + model），这是行业通用接口，**换平台不用改代码，只改 3 个环境变量**！（因为 constants.ts 里用的是 `process.env.DEEPSEEK_xxx`，从环境变量读）

### 省钱方案总览（按推荐顺序）

| 方案 | 成本 | 难度 | 适合场景 |
|------|------|------|---------|
| ① SiliconFlow 平台 | 💸 约 DeepSeek 官网 1/4 价 | ⭐ 改 3 行 env | 要质量+便宜，中文好 |
| ② Mock 模式（假 AI） | 🆓 完全免费 | ⭐ 加几行判断 | 学数据库/调 UI 时用，不花一分钱 |
| ③ HuggingFace 免费额度 | 🆓 每日免费 | ⭐ 改 3 行 env | 项目已预装 SDK |
| ④ Ollama 本地跑模型 | 🆓 完全免费 | ⭐⭐⭐ 电脑够强 | 数据不出本机，完全离线 |

### 方案 ①（最推荐）：SiliconFlow

注册地址：https://siliconflow.cn/ — 新用户送免费额度

操作步骤：
1. 注册拿 API Key（sk- 开头）
2. 项目根目录新建 `.env.local`（不要提交 git！）：

```env
# .env.local
DEEPSEEK_API_KEY="sk-你的SiliconFlowKey"
DEEPSEEK_BASE_URL="https://api.siliconflow.cn/v1"

# 完全免费选项（阿里 Qwen2.5-7B，中文很好）：
DEEPSEEK_MODEL="Qwen/Qwen2.5-7B-Instruct"

# 还是想用 DeepSeek 官方模型但更便宜：
# DEEPSEEK_MODEL="deepseek-ai/DeepSeek-V3"
```

**不用改代码！** interview-graph.ts、scorer.ts、deepseek.ts 一行不用动，因为它们本来就从 constants.ts 读 env 变量。

### 方案 ②：Mock 模式（学习阶段强烈推荐）

学 Day 5/6 的数据库三层架构时，**根本不需要真实 AI 回复**，用写死的回答就能跑通数据库全链路。

建议实现思路：
```
加一个环境变量 MOCK_AI=true 时：
  用户说任何话 → 返回写死的问题列表循环
  比如：
    第 1 轮："请做个自我介绍"
    第 2 轮："说说你做过的最有挑战的项目"
    第 3 轮："说说你对 XXX 技术的理解"
  评分也用随机数，数据库照样 createSession + createMessage + completeInterview
```

**好处：** 学数据库时每次跑都不花钱，想测几次测几次。等 UI 和流程都跑通了再切回真 AI。
