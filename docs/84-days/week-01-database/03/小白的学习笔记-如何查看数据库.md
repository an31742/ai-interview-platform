## 二、方法 1：sqlite3 命令行（最简单，不依赖任何工具）

### 正确用法

```bash
sqlite3 /Users/maxiangan/Desktop/project/ai/dev.db "SELECT * FROM User;"
```

**注意：** 这是在**终端里**直接执行的命令，不是在 sqlite3 里面输入。

### 如果已经进入了 sqlite3 交互环境

```bash
# 在终端里执行这个进入 sqlite3
sqlite3 /Users/maxiangan/Desktop/project/ai/dev.db

# 看到 sqlite> 提示符后，输入 SQL 语句
sqlite> SELECT * FROM User;

# 退出 sqlite3
sqlite> .quit
```

### 常见错误

```
❌ 错误：SELECT * FORM User;    ← FROM 拼错了
❌ 错误：SELECT * FROMM User;   ← 多打了一个 M
❌ 错误：在 sqlite> 里面输入 sqlite3 xxx  ← 命令是终端的，不是 sqlite 的
```

### 验证结果

```
cmrw3esqs00001t5sx55vxcwv|test@example.com|测试用户|2026-07-22T13:03:00.100+00:00
       ↑                       ↑              ↑                  ↑
     id(cuid)                email         name             createdAt

数据库里真的有一行数据！不是模拟的。
```

## 三、方法 2：Prisma Studio（图形界面）

### 为什么之前跑不了

```
Prisma 7 + 你的 Node.js 版本（v22.12.0）：
  需要 better-sqlite3 这个包来连接 SQLite
  但这个包是用 Node.js 的 C++ 插件编译的
  你的 Node 版本和 better-sqlite3 编译时的版本不匹配
  → 报错：NODE_MODULE_VERSION 不匹配

就像：
  你有一把钥匙（better-sqlite3）但锁（Node.js 版本）换过了
  钥匙插不进去
```

### 怎么解决的

```bash
# 第 1 步：安装 nvm（Node 版本管理器）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.2/install.sh | bash
# → 重启终端

# 第 2 步：安装最新 Node.js 22
nvm install 22

# 第 3 步：重新编译 better-sqlite3
npm rebuild better-sqlite3

# 第 4 步：启动 Prisma Studio（浏览器打开 http://localhost:5555）
npx prisma studio
```

### 为什么会有这种问题

```
Node.js 升级频繁：
  你的电脑原来装的是 v22.12.0
  nvm install 22 装了最新的 v22.x（版本号更高了）
  better-sqlite3 这个 C++ 插件需要重新编译才能匹配新版本
  
这不是 Prisma 的问题，是"原生模块（C++ 插件）兼容性问题"
很多工具（node-sass、sharp、bcrypt）都有类似的问题
```

## 四、方法 3：VS Code 插件（小白最友好，不依赖版本）

```
VS Code 左侧 → 扩展（Cmd+Shift+X）→ 搜索 "SQLite Viewer"
→ 安装 → 在文件树找到 dev.db → 右键 Open With → SQLite Viewer

优点：
  - 不依赖 Prisma 版本
  - 不依赖 Node 版本
  - 像 Excel 一样点开就看
  - 以后永远能用
```

## 五、今天学到的本质

```
知识 1：sqlite3 是一个命令行工具
  直接读 .db 文件，不需要经过 Prisma
  "sqlite3 数据库文件路径 SQL语句"
  
知识 2：Prisma Studio 也是读数据库文件
  它不是 Prisma 的核心功能，只是一个"附赠的查看器"
  不能用的原因不是 Prisma 坏了，是版本兼容问题
  
知识 3：nvm 是什么
  Node Version Manager = Node 版本管理器
  可以随时切换 Node.js 版本
  后面学其他项目时也会用到
```
