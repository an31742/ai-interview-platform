## 二、今天我理解的最重要的东西

### 后端数据流完整链路

```
前端页面 / 按钮
    ↓ fetch("/api/auth/login")
Controller（login/route.ts）    ← 接请求、调 Service、返回响应
    ↓ 调用
Service（user.service.ts）     ← 业务规则（验密码、去密码）
    ↓ 调用
Repository（user.repository.ts） ← 查数据库
    ↓ Prisma
Database（dev.db）             ← 真正存数据的地方
    ↑
数据原路返回 → 前端拿到 → 页面显示
```

### 我的理解（老师说完全正确）

```
前端调用 → routes → service → Repository → 数据库
找到数据 → 原路返回
```

### React Context 是什么

Context = 前端的"公共信箱"

```
createContext = 装一个信箱
Provider      = 管理员放信（放 user、login 函数）
useAuth()     = 你打开信箱拿信

const { login } = useAuth()
这里的 login 就是帮你调 /api/auth/login 的函数
不是 API 本身，而是"调 API 的那个函数"
```
